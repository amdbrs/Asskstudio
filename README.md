# ASSK Studio - Portfolio & Agency Website

## Deployment

```bash
cd frontend
yarn install
yarn build
```

## Environment Setup

Create `.env` in `/frontend`:
```
REACT_APP_BACKEND_URL=https://your-backend-url.com
```

## Stack
- Frontend: React, Tailwind CSS, Framer Motion
- Backend: FastAPI, MongoDB, Resend (email)
